# RAG Log Analyzer

A simple Python-based tool that analyzes SSH logs, detects suspicious activity such as brute-force attempts, and explains the findings using a security knowledge base with RAG.

## Features

- SSH log analysis
- Brute-force detection
- Suspicious activity detection
- RAG-based security explanations
- MITRE ATT&CK references
- Optional Streamlit interface

## Tech Stack

Python | RAG | TF-IDF | Streamlit | Ollama
